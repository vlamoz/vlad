# Personal Portfolio Website

Source of [vlamoz.me](https://vlamoz.me): a single-page portfolio and printable CV built with React, TypeScript and Vite, in three languages, with light and dark themes.

## Tech Stack

- **React 19** with **TypeScript 6**
- **Vite 8** (Rolldown) for dev server and builds
- **Tailwind CSS 4**, configured in `src/index.css` (`@theme`), dark mode via the `dark` class
- **i18next / react-i18next**: English, Spanish, Estonian
- **Framer Motion** through `LazyMotion` + `m.*` elements, to keep the bundle small
- **Lucide React** icons, **react-syntax-highlighter** (Prism Light, Java only) for the project code cards
- **Formspree** for the contact form, **Vercel** Analytics and Speed Insights

## Features

- Light/dark theme, following the system preference until the visitor picks one
- Each language has its own address (`/`, `/es/`, `/et/`); otherwise the visitor's last choice or the browser language decides. Only English is in the main bundle; each other language loads as one small chunk before the first render, so there's no flash of English
- SEO: each language is pre-rendered at build time into static HTML with its title, description, canonical URL, hreflang links, Open Graph/Twitter tags and JSON-LD; the sitemap is generated too
- "Download CV" prints the page as a CV: `print:` utilities on the components hide the screen-only parts and tighten the layout
- Responsive, mobile-first layout

## Getting Started

Requires Node.js 20.19+ or 22.12+ (Vite 8).

```bash
npm install
cp .env.example .env   # then set your Formspree endpoint
npm run dev            # http://localhost:3000
```

### Scripts

```bash
npm run dev        # Development server on port 3000
npm run build      # Type-check, production build and per-language pre-render into dist/
npm run preview    # Serve the production build
npm run lint       # ESLint
```

### Environment

| Variable | Purpose |
|---|---|
| `VITE_FORMSPREE_ENDPOINT` | Formspree form URL the contact form posts to (`https://formspree.io/f/<id>`) |

`.env` is not committed. On Vercel, set the variable in the project's environment settings.

## Project Structure

```
src/
├── components/   # Page sections (Hero, About, Skills, Projects, Experience, Contact, ...) and shared pieces
├── contexts/     # ThemeContext
├── data/         # Work history, skill categories, personal profile (email, LinkedIn)
├── hooks/        # useContactForm, useSEO
├── locales/      # <lng>/<namespace>.json translations
├── utils/        # Small helpers
└── i18n.ts       # Language list, i18next setup and lazy language loading
public/           # Favicons, og-image.jpg, robots.txt, sitemap.xml
```

## Editing Content

- **Texts** are in `src/locales/<lng>/*.json`, one file per page section. Change all three languages together.
- **Jobs and projects**: structure (years, position key, locations) is in `src/data/workExperience.ts`; company names, descriptions, highlights and tags are in `src/locales/<lng>/data.json` under `projects.<id>`; position names are under `common.positions` in `common.json`.
- **Skills**: category order in `src/data/skills.ts`; titles and items in `src/locales/<lng>/skills.json`.
- **Contact details**: `src/data/profile.ts`.
- **Project code cards**: `CODE_SNIPPETS` in `src/components/ProjectPlaceholder.tsx`, keyed by project id.
- **Social preview image**: `public/og-image.jpg` (1200×630). The pre-rendered pages carry the Open Graph tags for link previewers that don't run JavaScript.

### Adding a Language

1. Add it to `LANGUAGES` in `src/i18n.ts` (code, name, flag, Open Graph locale).
2. Copy `src/locales/en/` to `src/locales/<code>/` and translate.
3. The page `/<code>/`, its hreflang links and its sitemap entry are generated by the build.
